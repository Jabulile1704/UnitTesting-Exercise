C# Unit Testing Exercise

A practical C# unit testing project developed to demonstrate the fundamentals of software testing using automated test cases in Visual Studio. The project focuses on validating application functionality, improving code reliability, and understanding core unit testing principles within the .NET environment.

Features
Unit testing with test methods
Assertions and expected outcomes
Test-driven validation
Error and exception testing
Organized test structure
C# and .NET testing fundamentals
Technologies Used
C#
.NET
MSTest / NUnit / xUnit
Visual Studio
